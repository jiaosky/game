# 一杯到底

单文件 HTML 水排序游戏，适配手机竖屏，可直接双击 `index.html` 运行。

## 玩法

- 四档难度，每档 50 关：懦夫、菜狗、笨笨、天龙人。
- 订单、步数上限、连击计分、三星评价和关卡地图。
- 毒舌裁判：连击、断连、低步数和失败结算都会递进式拱火，专门刺激你再开一局。
- 隐藏色与带数字的隐藏杯；隐藏杯会随消除数逐步解锁。
- 清空全部色块才算通关；每局生成后都会用求解器验证，保证存在完整清空的解法。
- 每个难度开局有 1 套道具库存（空试管、提示、撤回各 1 件），库存跨关保留，上限分别为 3 / 2 / 3。
- 每个难度首次通过第 5、10、15…50 关时，自动随机补给 1 件道具；满仓时兑换 300 分，重复刷关不重复发放。
- “菜狗急救站”每局最多生效 1 次：只有空试管、提示、撤回全部为 0 时，点击才会随机获得 1 件临时道具；未使用会在下一关作废。道具还没用完时点击只会触发嘲讽。
- 当前对局会自动保存，刷新或被手机后台回收后可继续。

## 本地运行

直接打开 `E:\workspace\game\index.html`，或启动本地静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 菜狗急救

急救道具只对当前关卡有效，不进入跨关库存。每局只能领取 1 次，且必须先把三种道具全部用完。临时道具若未使用，进入下一关会自动清空。

## 发布

GitHub Pages 使用 `docs/index.html`。修改根目录 `index.html` 后，需要同步到 `docs/index.html`。

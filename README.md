# 一杯到底

单文件 HTML 水排序游戏，适配手机竖屏，可直接双击 `index.html` 运行。

## 玩法

- 四档难度，每档 50 关：懦夫、菜狗、笨笨、天龙人。
- 订单、步数上限、连击计分、三星评价和关卡地图。
- 隐藏色与带数字的隐藏杯；隐藏杯会随消除数逐步解锁。
- 每局生成后都会用求解器验证，保证存在可完成订单的解法。
- 空试管、提示、撤回每局各 1 次；重开只重置棋盘，不返还已用道具。
- 当前对局会自动保存，刷新或被手机后台回收后可继续。

## 本地运行

直接打开 `E:\workspace\game\index.html`，或启动本地静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 发布

GitHub Pages 使用 `docs/index.html`。修改根目录 `index.html` 后，需要同步到 `docs/index.html`。
